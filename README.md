This is a demo of a game I am currently working on. It features physics-based gameplay and mechanics such as dashing, shooting, and special abilities. At the moment, the game includes the first playable ship and a static enemy.

Controls
Movement: WASD or Arrow Keys
Shoot: I
Rotation: Y / U
Ability: O
Dash: Shift

The game is planned for a future release on Valve Corporation's Steam platform. Currently, I am working on additional ship designs, maps, enemies, and new gameplay mechanics.

This is only an early demo, so content and features are still very limited compared to the planned final version.
